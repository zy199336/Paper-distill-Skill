# Writing Workflow

Status: pre-corpus template. Replace or enrich with `scripts/sync_skills_from_synthesis.py` after extraction.

## Runtime steps

1. Identify task type: draft, polish, restructure, translate, expand, reduce overclaiming, or improve transitions.
2. Identify the target section and its function in the paper outline.
3. Infer a minimal local outline if none is provided and mark assumptions.
4. Select the relevant section template.
5. Write or revise text to serve the section function.
6. Check whether every claim has evidence or is hedged.
7. Flag missing definitions, data, metrics, citations, or experimental details.
