## Transition targets

- Background -> gap: narrow from broad importance to a specific unresolved limitation.
- Gap -> contribution: state how the proposed work directly addresses the limitation.
- Scenario -> formulation: turn real-world objects into model entities.
- Formulation -> method: show how the method solves or approximates the formulated problem.
- Method -> experiment: explain what evidence is needed to validate the method.
- Results -> implication: interpret findings within tested boundaries.
- Limitation -> future work: move from current boundary to a realistic next step.

## Checks

- Avoid abrupt topic jumps between paragraphs.
- Make the first sentence of each paragraph connect to the previous paragraph's unresolved point.
