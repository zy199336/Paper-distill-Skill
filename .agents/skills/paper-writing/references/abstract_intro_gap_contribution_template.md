# Abstract Introduction Gap Contribution Template

Status: pre-corpus template. Replace TODO source IDs after synthesis.

## Abstract

Move order:
1. Context
2. Specific problem
3. Gap or limitation in existing approaches
4. Proposed method or framework
5. Validation setting
6. Key findings
7. Implication within evidence boundary

## Introduction

Paragraph moves:
1. Establish domain importance.
2. Narrow to a concrete technical or empirical challenge.
3. Group prior work by approach, not by author list.
4. State a specific gap.
5. Present the proposed work.
6. List contributions with evidence paths.
7. Optionally describe paper organization.

## Contribution checks

- Each contribution should be testable or demonstrable.
- Avoid "first", "novel", or "significant" unless evidence supports it.
