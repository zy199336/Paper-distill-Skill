# Methodology Writing Template

Status: pre-corpus template. Replace TODO source IDs after synthesis.

## Writing order

1. Give a method overview before details.
2. State input and output.
3. Present modules in execution order or logical dependency order.
4. Explain formulas and algorithms in prose.
5. Link each module to the problem formulation or research gap.
6. Include reproducibility details where available.
7. Flag missing settings rather than inventing them.

## Claim control

- Use "is designed to", "aims to", or "enables" when effectiveness has not yet been validated.
- Reserve strong performance claims for results-backed statements.
