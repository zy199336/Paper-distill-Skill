# Problem Formulation Template

Status: pre-corpus template. Replace TODO source IDs after synthesis.

## Recommended order

1. Application scenario: explain the real setting before symbols.
2. Decision or analysis problem: state what must be optimized, predicted, classified, estimated, or assessed.
3. Assumptions: list scope boundaries and simplifications.
4. Entities: define actors, objects, network elements, time periods, or samples.
5. Sets and indices: introduce notation only after the reader understands the scenario.
6. Parameters and data: separate observed inputs from decision variables.
7. Variables: define controllable or estimated quantities.
8. Objective: connect the mathematical target to the stated problem.
9. Constraints: group by physical, logical, safety, capacity, fairness, budget, or domain requirements when relevant.
10. Mapping back: explain how the formulation supports the method and experiments.

## Reviewer-risk checks

- Are all variables used in equations defined?
- Are assumptions visible before they affect results?
- Does each constraint have a real-world meaning?
- Does the formulation support the claimed contribution?
