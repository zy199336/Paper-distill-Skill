# Method Section Template

Status: pre-corpus template. Replace TODO source IDs after synthesis.

## Recommended order

1. Method overview: one paragraph describing the full pipeline.
2. Input-output relationship: state what enters and what the method returns.
3. Module sequence: split the method into reader-friendly components.
4. Link to formulation: show which objective, constraint, or assumption each module addresses.
5. Equations or algorithms: explain symbols and steps in prose.
6. Reproducibility details: include parameter settings, implementation choices, convergence criteria, or training details as relevant.
7. Complexity or runtime: include when the method's practicality depends on it.

## Reviewer-risk checks

- Does the method solve the stated problem rather than a nearby problem?
- Are algorithm steps reproducible?
- Are implementation details sufficient for evaluation?
