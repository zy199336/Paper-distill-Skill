# Outline Workflow

Status: pre-corpus template. Replace or enrich with `scripts/sync_skills_from_synthesis.py` after extraction.

## Runtime steps

1. Identify the user's research topic, domain, paper type, method type, data/scenario, and intended contribution.
2. If target venue is missing, do not invent it. Use corpus-derived domain or paper-type patterns only when available.
3. Build the storyline: Background -> Gap -> Problem -> Formulation -> Method -> Validation -> Implication.
4. Select a section sequence that matches the paper type.
5. Specify each section's function, required content, expected figures/tables/equations, and reviewer risks.
6. Decide whether Problem Formulation is a standalone section or part of Methodology.
7. Plan validation so that experiments directly test the claimed contribution.
8. Mark assumptions and missing information.
